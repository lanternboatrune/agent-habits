# @local/agent-habits

调整 AI 的工作习性：汇报节奏、沟通方式、执行方式。全部设置都在 DSH「设置 → AI 习性」里用分档滑块调整，点击档位即保存；下一轮对话生效。

## 设置项

三组共 7 个分档滑块：

| 组 | 设置 | 档位（从低到高） | 宿主行为 |
|---|---|---|---|
| 汇报节奏 | 播报密度 | 极少 / 少 / 适中 / 多 / 很多 | 每约 0（仅节点）/30/10/5/2 分钟提醒播报一次 |
| 汇报节奏 | 停顿频率 | 不停 / 少 / 适中 / 多 / 频繁 | 每约 0/30/10/5/2 分钟停一次，汇报后等回复 |
| 汇报节奏 | 确认时机 | 关 / 只提示 / 任务前确认 | 在重要任务开始前停下说明计划、等确认（不弹提问框） |
| 沟通方式 | 提问风格 | 不问 / 关键处停 / 多提问 | 信息不足时的处理方式 |
| 沟通方式 | 回答详略 | 结论优先 / 适中 / 详细 | 回复的展开程度 |
| 执行方式 | 思考深度 | 先动手 / 平衡 / 先想清楚 | 动手前的规划程度 |
| 执行方式 | 执行节奏 | 小步验证 / 平衡 / 批量执行 | 工具调用的合并程度 |

默认：播报密度「适中」、停顿「不停」、确认时机「任务前确认」、提问「关键处停」、详略「适中」、思考「平衡」、执行「平衡」。

另有总开关「启用习性调整」，关闭后不注入任何规则、也不做定时提醒。

## 实现

- 宿主 `index.js`：把档位翻译成系统提示段落（`user:agent-habits`，order 10155），并在 `agent/pre-step` 里按壁钟时间注入播报/停顿提醒；状态存插件目录 `state.json`。
- 客户端 `client.js`：注册 `settings.section` + `settings.section.icon` 插槽；分档滑块用原生 range 拖动、按档吸附，档位文字可直接点击。
- bridge：`POST /api/agent-habits`，`{ action: "get" | "set" | "reset" }`；只接受回环地址、`application/json`、≤64KB。
- 所有文案都用 `--dsw-alias-*` 主题 token，不读其它插件 DOM。

## 安装与生效

已在当前 profile 中以 `link:` 方式安装。修改宿主或客户端后需要**完全退出 DSH（含托盘）再打开**才会加载新代码，刷新页面不够。

## 与旧插件的关系

取代 `dsh-progress-rules`（已在 profile 中停用）。规则文本、UI 与实现均为本插件自写，没有复制其它插件代码。
